# M5A11 - Regressão

Notebook do módulo 5 (Máquinas Preditivas) do curso Cientista de Dados na Prática.

- **Regressão linear simples:** prevê o preço de diamantes a partir do peso (`carat`) com scikit-learn, usando `diamonds.csv` (53.940 registros). R² no teste: 84,7%.
- **Regressão com statsmodels:** relação entre idade e peso usando `dados/pesos.csv`. R² = 0,986.

## Como rodar

```bash
pip install pandas seaborn scikit-learn statsmodels notebook
jupyter notebook M5A11_Regressão.ipynb
```
